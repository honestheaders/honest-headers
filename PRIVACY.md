# Privacy Policy – Honest Headers

_Last updated: 27 September 2026_

Honest Headers is published by Honest Tools.

**We do not collect, store, sell or share any personal data.**

- The header rules and profiles you create are stored only in your own browser (`chrome.storage.local`). They are never sent to us or anyone else.
- The extension makes no network requests of its own. There is no analytics, no telemetry, no advertising and no remotely hosted code.
- The extension does not read the content of the pages you visit. It only asks Chrome to change the HTTP headers you configured, using Chrome's built-in declarativeNetRequest rules.
- If you export a backup, the file is saved to your own computer and nowhere else.

If this ever changes, this page will be updated before the change is released, and the change will be clearly explained in the store listing.

Questions: please open an issue on this project's GitHub page.
